- `Others` 是残差类别，不代表单一资产群体。

## 更早历史的公开数据可行性（2026-09-08 核验）

- Binance REST `openInterestHist` 仅保留最近 1 个月，不能直接用于多年回填。
- Binance Data Vision 的公开 S3 归档存在 `daily/metrics` 文件；实测 USD-M `BTCUSDT` 从 2020-09-01 开始，ETH、BNB、ADA、XRP、SOL、DOGE、DOT、LINK、LTC、BCH、EOS、TRX、ETC、FIL、UNI 等主要合约均从 2021-12-01 开始。
- Binance COIN-M `BTCUSD_PERP` 和 `ETHUSD_PERP` 的公开 metrics 归档实测从 2021-07-08 开始。
- 官方仓库已有历史 metrics 缺日、零值和不完整文件的公开问题记录，回填时必须做逐文件完整性检查、缺口标记和异常值审计。
- Bybit V5 公共 OI 接口可回溯至合约上线时间并支持 1d 与游标分页；主域名在当前网络不可用，但官方区域域名 `api.bybit.kz` 可访问，已完成全量采集与重叠验证。
- OKX 的合约级 OI 历史接口在 2024-06-13 才加入公开 API，无法作为 2021 年以前全市场还原的主要依据。

因此，可信的第一版历史延伸应从 2021-12-01 开始，并定义为“固定公开交易所覆盖的重建序列”，不能命名为 Coinalyze 全市场原序列。2020-09 至 2021-11 只能形成覆盖不完整的 BTC/少量主流币参考段，不适合计算完整的 BTC/ETH/Others dominance。

## 2021 年后分段可行性复核（2026-09-08）

### Coinalyze 实测边界

- 官方文档说明日线数据不会滚动删除，但这不等于平台从 2021 年就有采集记录。
- 使用同一 API 对 13 个代表性 BTC 合约做分段查询：2021-01-01 至 2022-01-01 返回空；Binance `BTCUSDT_PERP.A` 最早从 2022-07-30 返回日线。
- 2021-01-01 至 2023-01-01 的跨交易所 BTC 样本中，BitMEX、Deribit、OKX、HTX、Bybit、Binance、Bitfinex 均从 2022-07-30 左右开始；dYdX 样本从 2022-07-27 开始。Phemex、Kraken、Gate.io 样本在该区间没有返回。
- API 对当前目录之外的若干已退市 Binance 合约代码返回空，因此不能仅靠猜测历史 symbol 补回退市合约；需要另建历史合约清单。
- 结论：Coinalyze 可作为 2022-07-30 以后主干数据源，不能直接解决 2021 至 2022-07-29。

### 分段评级

- 2022-07-30 至今：高可实现。以 Coinalyze 日线为主，补历史合约清单后可做到趋势和绝大多数日点高度接近；仍不能保证与原图逐点一致。
- 2021-12-01 至 2022-07-29：中等可实现。Binance + Bybit 已形成主要公开主干；Bitfinex、Kraken 尚受当前网络阻断，Gate.io 有 180 日限制；缺少 OKX、HTX、BitMEX、Deribit 完整历史仍会产生系统性偏差。
- 2021-01-01 至 2021-11-30：低到中等。可做 BTC/ETH 与少量主流币的覆盖型参考序列，但 `Others` 分母不完整，不应直接与后段无缝连线或标成全市场 dominance。

如果允许使用付费聚合库，Coin Metrics 与 CoinGlass 都公开了合约级或交易所级历史 OI 接口文档，并包含已退市合约相关能力；这会显著提高 2021 段的覆盖率，但不属于无成本公开数据方案。

- 已生成 2021-12-01 至 2026-09-19 的分段研究序列，共 1,754 个连续日点。
- 2021-12-01 至 2022-07-29 为 Binance USD-M/COIN-M + Bybit linear/inverse 固定交易所段，共 241 日；2022-07-30 起切换为 Coinalyze 当前合约宇宙段。
- Binance 公共归档采集覆盖 2021-12-01 至 2022-08-31，共 57,588 条合约日观测、274 个连续日点、每日 183–245 个市场，未解决下载或解析失败为 0。
- Bybit V5 采集发现当前 linear/inverse 合约 888 个，其中 132 个符合报价与上线日期条件；获得 29,710 条合约日观测、274 个连续日点，失败 0。2022-07-30 的 Bybit 总 OI 为约 27.29 亿美元，Coinalyze 同交易所为约 27.07 亿美元。
- Bybit 使用官方返回的双边合计 `openInterest`；重叠期总 OI 相对 Coinalyze 的均值比例约 1.0034，BTC/ETH/Others dominance 的平均绝对差分别约 0.89/0.54/0.58 pp。当前合约目录可能遗漏已经退市的历史合约。
- 7 个旧 Binance 文件没有可取得的官方 SHA-256，但 ZIP CRC 校验通过；这些文件保留并标记为 `unverified_checksums`，没有静默当成已通过官方校验。
- Coinalyze 早期回填查询了 1,007 个在 2024-09-08 已有历史的当前合约，得到 2022-07-27 至 2024-09-07 的 774 个连续日点；其中 2022-07-27 至 2022-07-29 只有 dYdX 等极少覆盖，因此合并时从 2022-07-30 才启用。
- 合并序列无日期缺口、无负 OI，BTC + ETH + Others 最大求和误差约为 `1e-8`；来源只在 2022-07-30 切换一次。

### 重叠期偏差

在 2022-07-30 至 2022-08-31 的 33 日重叠区间，Binance + Bybit 固定交易所口径减 Coinalyze 当前合约宇宙口径：

| 指标 | 平均有符号差 | 平均绝对差 | 最大绝对差 |
|---|---:|---:|---:|
| BTC | -2.8505 pp | 2.8505 pp | 5.1390 pp |
| ETH | -1.9560 pp | 1.9560 pp | 3.6777 pp |
| Others | +4.8065 pp | 4.8065 pp | 6.0758 pp |

这不是可用常数修正消除的微小误差，而是交易所覆盖和历史合约宇宙不同造成的结构差异。因此没有对早期数据做平滑、缩放或拼接校准；图中用虚线和切换标记显式区分。2021-01 至 2021-11 仍未并入，因为免费公开 API 无法可靠恢复完整的 `Others` 分母。

加入 Bybit 后，BTC 与 Others 的重叠期平均绝对偏差分别从 Binance-only 的 5.75/6.94 pp 降至 2.85/4.81 pp；ETH 从 1.20 pp 升至 1.96 pp，说明剩余误差是交易所资产结构差异，不能用单一比例校正。
